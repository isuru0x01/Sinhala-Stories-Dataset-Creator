Figure 1. Architecture of the three-component crowdsourced Sinhala text ingestion and automated merge pipeline.
Legend: Schematic representation of the crowdsourced data collection and ingestion architecture designed for high-throughput, conflict-free Sinhala text dataset creation. (1) Client Submission Interface built with Streamlit handles text entry, Unicode NFC normalization, quality bounds, dual-tier deduplication, and packaging into isolated single-entry JSONL files with local offline buffering. (2) Fault-Tolerant Staged File Queue leverages remote Hugging Face Hub micro-commits in pending/ to eliminate concurrent write conflicts. (3) Automated Merge Workflow orchestrated via scheduled GitHub Actions executes schema alignment, incremental append to Parquet, hash index synchronization, and an atomic commit-and-purge operation.
